## 1. 目标

地图仍由种子随机生成，但相邻区域共享连续的环境条件，地理差异拥有可解释的来源。山脉、海陆位置、纬度、水汽、水系与土壤共同决定地区特征，随机噪声提供变化与细节。

结果应能解释这些情形：

- 为什么这一侧山坡多雨，而另一侧干燥。
- 为什么大陆腹地比相同纬度的迎风海岸缺水。
- 为什么当地降水少，却有一条来自远方湿润流域的大河。
- 为什么高原海拔很高，却仍存在平坦、可建设的土地。
- 为什么大片干旱区里，只有一部分河谷具有农业潜力。
- 为什么建设灌溉设施能够改变农业条件，却不改变当地天然气候。

地图的作用是为国家规划、农业、水利、建设、外交与安全提供条件，不将游戏转成要求玩家管理所有自然过程的气候模拟器。

## 2. 现实规律与游戏规则的区别

### 2.1 肥沃地与沙漠可以相邻

不设「肥沃地不能邻接沙漠」的硬限制。尼罗河三角洲、干旱地区的灌溉河谷等都说明：区域气候干旱和局部农田存在并不矛盾。[NASA：尼罗河三角洲](https://science.nasa.gov/earth/earth-observatory/foggy-nile-152302/)、[NASA：阿塔卡马沙漠河谷](https://science.nasa.gov/earth/earth-observatory/lluta-river-chile-82296/)。

设计上应禁止的是没有机制支持、由独立随机分类制造的突兀跳变。山脉、河谷、海陆交界等可以形成明显边界，均一平坦地区的气候则通常应有更连续的过渡。

地块面积也很重要：一个地块可能横跨多个自然环境，不能将其主色当成内部百分之百相同的土地。

### 2.2 干旱不只取决于下雨多少

降水和蒸散需求共同决定水分紧张程度。相同降水条件下，较热地区可能面对更高的水分损失。气候干湿程度也不能单独决定农业产能，后者还受到生长季、土壤和水源等约束。[FAO：干旱环境](https://www.fao.org/4/T0122E/t0122e03.htm)、[FAO：干湿区定义与生长期](https://www.fao.org/4/x5308e/x5308e02.htm)。

本游戏拟采用简化干燥度作为分类输入，不宣称精确复现农业气象公式。

### 2.3 土壤肥力不等于湿润或绿色

土壤与母质、气候、生物、地形位置和形成时间有关，不能仅用降水量代替。地图上的森林色也不等于高产农田。[USDA NRCS：土壤形成](https://www.nrcs.usda.gov/sites/default/files/2022-11/from-the-surface-down.pdf)。

建议分开表示天然土壤条件、作物生长适宜度、可耕面积和实际农业生产能力。后者待人口、技术、设备、肥料与设施接入后再计算。

## 3. 最初原型的具体局限（历史对照）

对照 `crates/world/src/lib.rs`，目前已经存在纬度与海拔温度修正、距海跳数、独立湿度噪声和简化雨影，并非完全独立随机赋值。但这些近似仍不足以构成完整的地理因果。

| 现状 | 局限 | 建议方向 |
| --- | --- | --- |
| 海拔由多尺度噪声生成 | 山地可能聚成斑块，缺少明确连续山脊与分水岭 | 增加山脊与高原结构，保留噪声细节 |
| 距海采用地块跳数 | 改变地块数量会改变“距海”的意义 | 按独立环境网格或已标定距离计算 |
| 只检查西侧相邻地块近似雨影 | 没有随纬度变化的风带，也不追踪水汽经过山脉后的变化 | 连续水汽场与简化输送 |
| 湿度同时参与降水、肥力、植被 | 容易将湿润、肥沃、农业高产混为一体 | 分开气候、水源、土壤与农业适宜度 |
| 平坦度主要由绝对海拔推算 | 高原被判不平，低海拔起伏可能被忽略 | 测量局部相对起伏和坡面结构 |
| 一个 Terrain 枚举混合平原、森林、沙漠、雪地 | 难表达森林丘陵、干旱高原、河谷农田等组合 | 拆分地貌、气候与地表覆盖 |
| 没有水系与集水区 | 淡水潜力仅依赖本地湿度，不能解释沙漠中的大河 | 增加流域、汇流、湖泊与出口 |
| 整块用一种标签 | 狭窄河谷可能被夸大成整块肥沃土地 | 保留内部面积比例与子地理特征 |

## 4. 推荐架构：自然环境与治理地块分开

Voronoi 仍作为可选择和治理的地块。气候、山川和河网使用独立的连续环境底层，随后汇总到多边形。

建议先以固定分辨率网格作为环境采样层，例如约 256 × 160，最终分辨率由实际生成耗时与河网表现确定。该网格不作为玩家操作单位，也不直接变成额外的行政地块。

### 4.1 带来的好处

- 同一种子下，调整 500 块或 1,000 块主要改变地块划分，而不是重新创造整套山川与气候。
- 河流能够穿过地块内部，不被强迫沿每条行政边界流动。
- 地块能够统计林地比例、干旱地比例、河谷面积和可耕面积。
- 环境生成可以缓存，界面改变图层不触发重新计算。
- 后续更换地块细分方案时，仍能沿用同一套自然底图。

### 4.2 必要约定

- 地形、气候、水系和地块撒点使用独立的种子子序列。
- 海平面由环境底图的面积分布确定，而非随 Voronoi 数量改变。
- 保留固定的生成器版本；新版种子不承诺复现旧版地图。
- 初期仍为不环绕矩形，边界输入和出水口必须显式定义；不把这一近似称为完整球面模型。
- 默认采用接近地球的日照、旋转与气候背景，是架空宜居星球的设计假设，而非所有行星的必然规律。
- 世界实际尺度和纬度范围在实现前统一设定。未标定距离之前，只能给出相对起伏和距离指数，不能将地图坐标直接当成公里或坡度角。

## 5. 生成顺序

### 5.1 海陆、山脉与地貌

形成大陆尺度起伏、山脊、高原、低地与盆地，再叠加局部噪声。先用可控的山脊生成方法，不立即模拟完整板块运动和亿年侵蚀。

平坦度从局部相对起伏推导，地貌同时考虑高度和起伏。这样可以区分高而平的高原与高而陡的山地。

### 5.2 纬度、温度与季节背景

纬度建立大范围热量背景，海拔修正局地温度，海陆性用于简化温差。模型应让环境变化由连续场决定，避免每一行纬度突然切换颜色。

接口预留逐月气候基准。实现范围可先采用简化季节分配，但不要把多年平均气候和单个月的天气波动混为一体。

全球风带与干湿带可以借鉴地球大气环流，但应作为趋势和概率背景，不硬性规定某纬线只能生成沙漠或森林。[NOAA：全球大气环流](https://www.noaa.gov/jetstream/global/global-atmospheric-circulations)。

### 5.3 风、水汽与降水

海洋作为主要水汽来源，在简化风场中输送。湿空气抬升时形成更明显降水，越过山脊后，背风侧可能更干。保留有限的局地变化，但不让噪声完全覆盖这些结构。[NOAA：山脉与雨影](https://oceantoday.noaa.gov/teekandtom/educators-guide/lesson-2.pdf)。

不固定全世界永远刮西风。初期可以用随纬度变化、平滑过渡的盛行风，暂不加入复杂季风、洋流反馈与大气流体方程。

输送应具有近似水汽预算：蒸发补充、上风输入、降水消耗、下风输出分别记录。水汽场迭代不能凭空逐轮变多。

### 5.4 干燥度与自然植被

根据降水、温度与简化蒸散需求推导气候干湿，再结合寒冷程度与季节性划分自然植被。表现上允许从湿润林地经过疏林、草地、半干旱地过渡到荒漠，不强行在任何边界插入固定数量过渡地块。

冷而干的地区同样可能缺水；不能把所有荒漠都写成“高温＋少雨”。积雪也不能只由固定海拔门槛永久决定。

### 5.5 汇水、河流与湖泊

降水中进入地表径流的部分沿地势汇集，形成支流与主干河流；流域用共同出口组织。河流流量受上游汇水影响，不能只看所在地区当天下不下雨。[USGS：流域与集水区](https://www.usgs.gov/water-science-school/science/watersheds-and-drainage-basins)。

实现时需要：

- 将数值噪声形成的小凹坑与有意保留的盆地区分处理。
- 让流向和累计汇流不存在循环，主要河流从高地向低处输送。
- 对封闭盆地生成湖泊、内流或蒸发出口，而非强迫所有河流入海。
- 边界流出单独标记，避免河流无解释消失。
- 保留支流汇合和流量，不能先画随机蓝线再赋予“河流”名字。
- 将天然可用水和未来可取用、可灌溉的水量区分；有河不等于无限水。

首轮不用水动力模型，也不承诺侵蚀塑造出完全自然的每条山谷。河网应先做到拓扑正确、与地势一致和拥有可信水源。

### 5.6 土壤与农业潜力

为地质母质、土壤厚度、有机质与侵蚀/沉积条件设置简化区域参数，再结合水分、生长温度与地形计算作物适宜度。

河流附近可以具有更好的水源或沉积条件，但不无条件把所有河岸变成最高肥力；山谷宽度、地形、水量与土壤条件仍有限制。

地块至少区分：

| 属性 | 回答的问题 |
| --- | --- |
| 土壤质量 | 土本身适不适合种植 |
| 生长适宜度 | 温度、生长季等是否适宜 |
| 可耕面积比例 | 整个地区有多少土地适合耕作 |
| 自然供水与河流可用水 | 水从哪里来、够不够 |
| 实际农业能力（后续） | 人、设施、技术、设备和投入是否到位 |

沙漠地块可以保留干旱气候，同时拥有一小部分具有灌溉开发潜力的河谷。建设不能自动改变整个地块的气候和面积组成。

### 5.7 地质与矿藏（初期后置，0.6.0 已完成基础）

矿产采用简化地质区与成矿适宜度，保留连续分布与局部差异。现代植被、降雨或海拔不应直接决定所有矿产。例如煤与古代植被被埋藏、压实等历史过程有关，不能只因今天长森林就出现煤矿。[USGS：煤的形成](https://www.usgs.gov/faqs/what-coal)。

本轮优先解决用户指出的地形、气候与土地关系；不急于宣称重建了完整成矿地质史。

### 5.8 汇总到 Voronoi 地块

按多边形覆盖环境采样的面积权重计算均值、范围与比例。地块表现为「温带／偏干＋丘陵＋草地为主＋局部河谷」，而非只能在森林、丘陵、沙漠之间三选一。

颜色继续由展示层选择主导属性，详情明确其他属性；气候图、植被图、农业潜力图显示各自含义，不让绿色同时代指森林、降水和肥力。

## 6. 不推荐的快捷修补

- 仅增加噪声层数，期待自然生成所有地理关系。
- 将「森林邻接沙漠」全部视为错误，一律用多数投票涂成一样。
- 把森林、沙漠的标签直接做平均，而不处理温度、水汽和地势。
- 给每条河两侧整块行政区无限淡水和高肥力。
- 以绝对海拔替代陡峭程度。
- 用今天的降雨和植被直接决定地下矿产。
- 为了视觉平滑而在地图上画与真实数据不同的气候或河流。

## 7. 如何成为国家治理玩法

| 地理特征 | 主动治理机会 | 相应条件与代价 |
| --- | --- | --- |
| 干旱河谷 | 灌溉、节水作物与水利开发 | 流域水量、设施、盐分与上下游分配 |
| 平坦高原 | 高原聚落、适宜产业与基础设施 | 温度、生长季、交通与服务成本 |
| 湿润低地 | 农业、城市与防洪建设 | 洪水、排水、土地竞争 |
| 山地两侧气候差异 | 地区专门化、跨区协作与交通工程 | 地形、生态与建设成本 |
| 跨境流域 | 水资源协定、联合工程与外交合作 | 上下游利益、履约与水量约束 |

这些是后续可能的玩法，不在本次地图设计讨论中直接实现。自然禀赋建立条件，玩家仍能通过建设、技术与合作改变发展空间。

## 9. 验收方式

### 规则与一致性

- 同种子和参数复现；环境分辨率与生成器版本纳入契约。
- 只改变 Voronoi 数量时，自然环境底层保持不变；地区统计允许随边界变化。
- 平坦高原不会仅因海拔高被判陡峭。
- 水汽、径流与汇流不在迭代中无限生成，不出现有向循环。
- 河流具有上游来源、明确下游与出口；干旱区大河可以依赖湿润上游。
- 土壤质量、自然水源、植被覆盖与农业适宜度可以分别说明。
- 河谷对区域资源的贡献受真实面积比例与水量约束。

### 控制案例

- 同纬度、同地形条件下比较湿润海岸和内陆。
- 给定主导风与山脉，检查迎风降水和背风干燥的方向性。
- 构建湿润上游—干旱下游案例，检查河流与农业潜力。
- 对比低海拔丘陵与高海拔平台的平坦度。
- 同样的年度降水、不同温度条件下比较水分压力。
- 测试封闭盆地和地图边界的出水处理。

这些案例验证简化规则的方向，不声称现实世界所有地区都严格符合一个模板。最终还需对多个随机种子进行视觉检查，确保地图具有大尺度结构、合理例外与可解释性。

## 10. 自然底层阶段收尾（0.6.0）

地理生成基础清单已完成至可服务治理原型的程度。完整板块、侵蚀改写地形、气象与三维地下模型继续后置，不作为进入国家玩法的前置条件。下一步需要通过项目、人口与月度结算验证环境数据是否形成合理的取舍；静态禀赋不等于实际建筑、产能或配水。详见 [本轮模型与阶段评估](GEOLOGY_SOIL_CONSTRUCTION.md)。


## 11. 气候生成质量校准（0.7.0）

功能覆盖之后补充地理分布验收：移除逐行东西向年输送及年雨量的月度权重分配，改为固定自然网格上的逐月二维输送、海陆热力差异形成的季风代理、季节移动雨带与沿途山地凝结。保留温度／潜在蒸散经验式与干旱分类阈值，不预设全球沙漠面积。地块仍一块一色。

控制案例验证南北方向的海洋水汽供应、同纬度沿海与内陆差异、迎风与背风差异、半球季节反相、雨带迁移和逐月水量守恒；另提供按等面积自然采样统计的五种子手动报告，覆盖大陆型和海洋型地图。算法、统计口径及不能模拟的现象见 [气候校准说明](CLIMATE_CALIBRATION.md)。
