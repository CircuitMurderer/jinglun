# 地图原型：实现约定（生成器 0.2.1）

> 已完成第一轮地理细化。完整方向见 [地理方案](GEOGRAPHY_PLAN.md)；专题 GPU 动效见 [技术评估](RENDERING_PLAN.md)，当前仍使用 SVG。

## 运行与数据边界

所有自然环境、Voronoi、气候、汇流、湖泊、指标和分区汇总在 Rust 执行。TS 根据地块汇总值选择颜色、绘制 Voronoi 多边形与可选河流线，管理选择、相机、图层、图例与中文详情。没有 PixiJS、deck.gl 或 WASM 依赖。

`crates/world/src/environment.rs` 生成与汇总自然环境，`hydrology.rs` 处理汇水与水量账本，`lib.rs` 处理配置、Voronoi 与世界组装。HTTP 仍由独立服务封装，计算在 `spawn_blocking` 中执行。

## 两套空间结构

- **自然环境：** 固定 256 × 160 等面积模型采样，世界范围 1,600 × 1,000 地图单位。自然海岸、山川、气候、河网不依赖地块数量与 Lloyd 次数。
- **治理分区：** 100—2,000 个 Voronoi 多边形，完整铺满矩形；Lloyd 采用面积质心。分区允许同时包含海洋、陆地和湖泊。
- **汇总：** 环境采样中心按最近种子归属到 Voronoi 分区，统计面积比例和陆地属性。面积极小、没有采样中心的地块使用质心附近的单点回退。

地块几何面积仍精确由多边形计算，内部面积组成是固定分辨率采样近似。调整分区后地区指标可能变化，但 `environment` 整体保持一致。自然底图指纹用于辅助识别，仍需结合生成器版本。

## 生成步骤

1. 从固定种子生成多尺度 Simplex 大陆轮廓，叠加局部细节、山脊结构与高原区域。
2. 在自然采样上确定海平面，陆域比例误差控制在约两个环境采样以内，独立于 Voronoi 数量。陆域口径包含内陆湖泊。
3. 由局部邻域相对起伏计算平坦度；结合海拔区分低地、高原、丘陵和山地。该平坦度是游戏指数，尚未把地图单位标定为真实公里或坡度角。
4. 使用 −75° 至 +75° 的纬度背景与海拔修正年均温，采用接近地球的宜居世界假设，不是完整球面模拟。
5. 两个相反方向的稳态水汽输送按纬度平滑混合，海面补充、凝结降水、边界输出分别记账；上坡加强凝结，背风侧保留水汽亏缺。局地噪声只调节输送参数。
6. 用温度与简化蒸散需求计算干湿指数。当前是经过游戏尺度校准的年平均近似，没有逐月天气、季风、洋流或完整大气环流。
7. 基于 Priority-Flood 思路求出溢流高度和无循环排水关系；普通坡面优先选择更陡的下坡，平坦水面用确定处理顺序解开流向。[算法背景](https://arxiv.org/abs/1511.04463)
8. 降水在蒸散、深层补给与地表径流之间分配；上游径流累积成河。小凹坑用于排水计算，不直接改变原始海拔。
9. 一定面积与深度、且汇入水量能够支持蒸发需求的凹地保留为基本溢流湖泊。湖泊附加蒸发从流量中扣除，干凹地不会只因形状低就画成蓝色。
10. 土壤质量由连续母质代理、环境条件、侵蚀与有限河谷沉积代理组成；雨养农业另受温度、平坦度、水分制约。潜在可耕面积与灌溉改善潜力分别保存。
11. 将连续自然属性汇总到地块，并返回可翻译的成因标识。自然地理层使用主导表现，详情保留地貌、气候与植被的独立属性。

## 字段与单位

| 字段 | 定义 |
| --- | --- |
| `area`、边长与坐标 | 地图单位及其平方，尚不是实际公里 |
| `elevation_m` | 地块全区海拔平均值，米；海底为负 |
| `temperature_c`、`rainfall_mm` | 区内陆地年平均近似；纯海域取附近自然采样 |
| `land_fraction` | 陆域占地块比例，含内陆湖泊 |
| `lake_fraction` | 湖泊占整个地块比例，不是陆域内部比例 |
| `is_land` | 陆域占比至少 50%，只表示分区主导类型 |
| `landform` | 区内陆地的主导地貌 |
| `thermal_zone`、`moisture_zone`、`vegetation` | 区内陆地各分类的主导类型，不互相代替 |
| `flatness` | 局部相对起伏推导的 0—100 指数 |
| `soil_quality` | 0—100 土壤条件；取代旧版混合意义的 `fertility` |
| `agricultural_suitability` | 0—100 雨养农业适宜度，不是产量 |
| `arable_fraction` | 在当前自然与附近水源代理条件下具有开发潜力的面积占全区比例；不代表已开垦 |
| `irrigation_potential` | 0—100 灌溉改善机会，尚未建设或批准取水 |
| `river_access` | 陆域采样中接近主河网或湖泊的比例指数，不是可无限领取的水量 |
| `resources[].potential` | 0—100 相对资源潜力，混合分区按陆域比例缩放 |
| `rivers[].flow_index` | 相对流量视觉指数，不是流速或立方米每秒 |

纯海域不赋予陆地资源。矿藏仍是独立连续地质潜力场，本轮没有实现沉积盆地和完整成矿历史。

## 水系与账本

- 河流沿自然采样排水关系流动，可以穿越治理地块；以支流汇合点、湖泊和出口分段。
- 页面的“河网分段”不是独立河流数量。边界陆地可以显式流出地图，海域出口与边界出口分开记录。
- 河水可以由湿润上游带入干旱下游；零上游来水不会凭空生成河流。
- 本轮只包含基本溢流湖泊，不包含封闭内流盆地、盐湖、真实动态蓄水、地下水回补河流或完整河道侵蚀。
- 水量账本单位为等面积采样上的模型水深和；不是实际体积。浮点误差允许在严格相对容差以内。

账本满足：

```text
水汽补充 ≈ 凝结降水 + 边界水汽输出
陆域降水 ≈ 陆地蒸散 + 深层补给 + 地表径流
地表径流 ≈ 湖泊附加蒸发 + 入海流出 + 地图边界流出
```

海域采样的水汽降水不计入陆地径流。水系几何与水量代理都来自 Rust，不靠前端装饰线伪造。

## 显示与拓扑

- 七个图层均采用整块单色填充：自然地理按主导地形，其他图层按地块汇总指标映射颜色。页面不再叠加细网格色带，底色边界与可选地块完全一致。
- 海洋面积过半的地块统一显示深海或浅海，陆地为主的地块使用陆域主导地形；混合区的内部比例保留在详情中。自然湖泊仅在成为地块主导地形时整块着色，不额外绘制局部湖泊色斑。
- 显示海岸线使用海陆地块之间的共边；自然采样海岸和色带路径仍保留在导出数据中，当前页面不绘制。改变地块密度会改变显示海岸的概括程度，不会重新生成环境场。
- 数值映射在色标上限饱和，例如降水 2,400 毫米，原始指标不被截断。海域在专题层保持水域底色，海拔层表达其深度。
- 河流仅作为默认关闭的可选线条叠加，按地块陆域轮廓裁剪，避免越过显示海岸；其源头与路径仍来自 Rust 汇流结果。
- 河流线宽仅用于表达相对强度，缩放时保持可读性，不代表实测河宽。
- 多边形共边邻接仍表示行政几何接触；`edges.kind` 按两端主导海陆类型粗分，不是实际海岸测量，也不是现成道路或通行权。
- 未来陆路、水路与港口应基于连续地表和实际设施检查，不能只把 `is_land` 当作唯一可达条件。

## 版本、存档与验证

当前生成器版本为 `0.2.1`。同版本、种子、参数可重复生成，跨版本不保证重现旧版世界。导出 JSON 包含完整自然色带、河湖、指标与地块；当前页面没有导入旧版世界功能。

Rust 验证覆盖：几何铺满与邻接、参数边界、同种子重放、不同分区密度下自然环境完全一致、平坦高原、雨影方向、水汽账本、无循环汇流、水量守恒、干旱下游来水、湿润凹地成湖与干凹地不成湖。TS 类型检查与浏览器验收覆盖新图层、选择、河湖开关、缩放和导出。

## i18n

新增标签、地理成因、字段说明、图例仍只由中文语言包提供。Rust 返回稳定标识与数据，前端负责 `t(key, params)` 和本地化数值格式。没有新增英文语言包。
