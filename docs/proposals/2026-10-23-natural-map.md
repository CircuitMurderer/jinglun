# 地图视觉升级提案：自然地理与治理分区分层

日期：2026-10-23。实现范围：Phase 1。PR 目标：CypherHK/jinglun 的 `Develop`。

## 目标与判断

让地图首先像一片有自然海岸、山川与植被的世界，而不是一张多边形统计图；同时保留分区治理、指标阅读和点击选择的准确性。现有粗糙感主要来自把 Voronoi 治理区直接用作可见海陆轮廓，不是 SVG 性能不足，也不是缺少 WASM。

保留 Rust 世界内核、HTTP API、React/SVG 与现有 PixiJS 河网。不开辟新模拟系统，不重写渲染引擎，不引入 WASM、Three.js 或额外 runtime 依赖。

## 两种视图

**经典地块**：现有整块单色方案保持可用，也是默认模式。所有专题仍按地块汇总，颜色与指标一致。

**自然地形**：仅在地形图层启用。海岸来自现有 256 × 160 高程场的零米等值轮廓；陆地内显示同一环境场的地形类别。Voronoi 保留为透明点击层，内部边界淡化并裁剪到自然陆域。海洋不是一块块多边形拼接。

切换表现不生成世界、不改变地块 ID / 邻接 / 统计 / 季节 / 选区 / 相机。进入气温、资源等专题时仍显示经典汇总图；回到地形时恢复用户选择。缺少新增表现数据的旧后端可以回退经典模式，并显示原因。

## 第一阶段的实现边界

1. Rust 增量输出独立、带版本的自然地形表现字段。使用线性插值 Marching Squares 从现有标量场提取闭合轮廓，不对治理多边形做独立圆角或随机抖动。原始自然环境、湖泊账本与游戏参数不变。
2. 新增可切换的 SVG 自然底图。海岸、陆域裁剪和河流裁剪使用同一份几何；内部地形边界来自类别采样的插值概括，不声称是额外精度的地理测量。
3. 透明多边形继续接收选择、悬停和拖动。允许一个治理区同时含海、陆、湖，不偷偷修改 `is_land` 或邻接规则。高亮完整治理区，是为了让管理边界与自然边界的区别可见。
4. 小地图使用同一自然轮廓与配色，跟随视图切换。深浅主题、移动窄屏与现有候选地比较继续可用。
5. 自然模式首轮使用 SVG 河网，按自然陆域裁剪；经典模式保持原有 PixiJS 与 SVG fallback。避免用仍按粗地块裁剪的 GPU 河网制造断流，暂不扩大 GPU 模块接口。
6. 加入几何与模式解析测试；固定种子比较 100 / 500 / 2,000 地块，检查视觉、交互、状态保持、主题、专题、重生成与河网切换。

## 第二阶段（本 PR 不做）

基于真实高程的 Hillshade、地形类别边界的受控概括、统一山地与森林符号、缩放分级地名/资源标记。内部类别边界仍可看出采样折线；仅加阴影不会自动消除这种痕迹。待国家归属成为正式模型后，再添加政治半透明覆盖与真正国界。当前不根据示意截图虚构国家、首都、道路、矿山或物流数据。

## 不采用的捷径

不只换颜色或无限增加地块数；不把 AI 生成图片当成可点击、可复现的真实世界；不把每个地块分别平滑导致共边裂缝；不以视觉几何重算资源、陆地比例或通行规则；不把新的视觉字段混入随机数序列。

## 验收与限制

- 同种子同配置：除新增 `environment.natural_surface` 外，JSON 与改动前逐字段一致。
- 同种子不同分区密度：自然轮廓一致，治理区数量和统计按既有规则改变。
- 切换模式/主题/月度/专题：不丢相机、选区、候选列表，不额外请求世界生成。
- 经典模式绘制、河网开关与降级不回归；自然模式不残留错误 GPU 遮罩。
- 轮廓闭合、孔洞保留、边界正确裁切，不把矩形世界边缘绘制成虚构海岸。
- 自然地形仍受原有 256 × 160 采样精度限制；平滑是插值，不是新增地理事实。
- 本 PR 的浏览器结果、命令、截图与未覆盖项另记于 `docs/verification/2026-10-23-natural-map.md`。

## 来源与依据

- 项目 `docs/MAP.md`、`docs/GEOGRAPHY_PLAN.md`：自然环境与治理分区已经分离；原显示方案刻意选择一块一色。
- `crates/world/src/environment.rs`：固定环境采样、原色带、海岸、水文与指纹。
- `frontend/src/map.ts`、`map-camera.ts`：SVG 地块与共享相机。
- `frontend/src/river-overlay.ts`、`pixi-rivers.ts`：既有 GPU 叠加及降级管理。

提案是本次改动的边界，不代表第二阶段已完成或美术质量已经通过用户验收。
