# 地质、土壤与建设条件（生成器 0.6.0）

这一轮完成自然环境清单最后三项基础：区域地质与有限矿藏、侵蚀沉积与土层深化、环境到建设条件的转换。计算全部在 Rust，TS 绘制地块、切图层、展示调查数据。原有水文及月度显示继续保留。

## 1. 世界尺度

采用每地图单位 10 公里的可调整游戏约定，现有 1,600 × 1,000 矩形表示约 16,000 × 10,000 公里的游戏范围。坐标依旧为地图单位，几何面积换算为平方公里；不是现实地球投影，也不把二维直线距离当作精确球面距离。

`environment.scale` 导出 `km_per_map_unit`、`sample_area_km2` 与 `water_unit_m3`。水文账本保留原始等面积采样水深和；每个原始水量单位乘以 `采样面积（平方公里）× 1,000` 即为按此游戏尺度估计的立方米。页面的共享水源与湖底渗漏使用百万立方米，避免重复保存大批单位换算字段。

这是统一单位的游戏标定，不是流域实测。改变这个约定必须升级生成器，重新评估储量、距离、用地与未来工程参数。

## 2. 地质与矿床

独立种子域形成 24 个经扰动的连续地质区，分为沉积盆地、古老基底、造山变质、岩浆岩四种背景。岩性为砂岩／页岩、古老结晶岩、变质岩、花岗岩／玄武岩的区域概括。它们不依赖今天的降水或植被，不模拟完整板块运动和地质年代。

矿藏先在固定 256 × 160 自然网格形成，再汇总给治理地块：

| 矿种 | 简化赋存背景 | 主要限制 |
| --- | --- | --- |
| 石材 | 各类陆域基岩 | 岩石强度、埋深、地形 |
| 煤炭 | 具有合适历史条件的沉积盆地 | 品位、埋深与区域连续性 |
| 铁矿 | 古老基底及造山背景优先，岩浆背景允许较弱潜力 | 品位、基岩强度、地形 |
| 石油 | 沉积盆地中的较深埋藏区 | 埋深、品位与技术难度 |
| 稀土 | 岩浆背景优先，部分古老基底允许较弱潜力 | 稀疏富集区、品位与基岩条件 |

这些是合成矿产系统的游戏筛选，不穷举现实成矿类型。煤属于沉积岩背景，稀土具有多种赋存方式，并不等同于“今天森林多就有煤”或“所有山脉都有稀土”。[USGS：煤的地质背景](https://pubs.usgs.gov/circ/c1143/html/text.html)、[USGS：稀土矿床类型](https://pubs.usgs.gov/publication/cir1454)。

同一地质区内相连的同矿种采样组成矿床。`environment.deposits` 是唯一矿床清单，记录估计资源单位、平均品位、参考埋深、面积和地质区。`cell.minerals` 保存该地块实际覆盖部分的份额；各地块份额之和等于矿床总估计量，不因 Voronoi 数量、Lloyd 次数或界面显示改变而增加。

估计量为有限的**游戏资源单位**，不是探明吨数或已建矿山的产量。品位与开采难度均为 0—100 指数，埋深使用米。地形与湖泊覆盖会进一步影响本地开采难度。未实现勘探、扣减库存、经济可采性、矿权、矿山项目、地下矿体三维几何或海底油气；这些应随采矿玩法接入。没有自然采样中心的极小地块可以回退地质标签，但不复制附近矿床储量。

## 3. 土层与物质搬运

母岩提供初始风化土层、砂质比例、抗蚀性等背景。参考植被覆盖、降水、温度与局部起伏共同影响侵蚀和有机质；不将湿润、森林、肥力和农业产量视为同一个指标。土壤形成受母质、气候、生物、地形和时间共同影响，是本简化的依据。[USDA NRCS：土壤形成与特性](https://www.nrcs.usda.gov/resources/education-and-teaching-materials/soil-facts)。

在 200 年参考区间内，土壤剥离量受初始可用土层约束，最多移走其 60%。物质沿无循环排水网络搬运：平缓地形更容易沉积，保留的湖盆截留搬运物，其余从海洋或边界出口离开。陆地活动土层最多承接到三米厚，剩余搬运物继续下行，不被截断丢弃。湖底截留量单独记账，不自动变成肥沃耕地。

`environment.sediment_budget` 使用参考区间的模型土体体积，满足：

```text
剥离体积 = 陆地沉积 + 湖盆截留 + 入海输出 + 边界输出
```

体积按统一游戏尺度估计，没有模拟压实、粒径分选或密度变化，不称为真实吨数。档案中的毫米／年为参考区间的平均强度，不是在玩家切换月份时重复侵蚀一次。

最终土层厚度、质地、有机质、淋溶代理和平坦度形成土壤质量；厚土或沉积物并不自动使肥力满值。根区储水容量由土层深度、砂质比例和有机质推导，限制在 20—240 毫米，已接入最终逐月土壤水桶。雨养农业与可耕条件因此受到新土层和水分结果影响。

生成顺序为：地质与初始土层 → 初步水文提供排水拓扑 → 参考侵蚀沉积 → 最终根区容量 → 重新计算季节水分与河湖。搬运只依赖固定地形、湖盆几何与参考气候，不依赖治理地块。海拔模型不被这次搬运重写；没有模拟长期河谷切割、海岸生长、湖盆填满后的水系重建或全局地形—气候反馈。

## 4. 自然条件如何服务建设

每个自然采样先判断条件，再汇总为整块比例，避免用地区平均平坦度推断“整块都能建设”。

- 海洋、年均水面、全年冻结地表、极陡区域与最高洪涝暴露区域不计入常规候选用地。
- 平坦度较高、洪涝暴露较低、常规施工月份足够的地方计为适建候选；其余可改善陆地计为需工程条件。
- 地形起伏、洪涝暴露、厚松散土层代理、林地清理及寒冷多雨月份形成 1—4.5 倍的自然成本系数。它不是完整预算、地基承载力实测或工程安全结论。
- 施工窗口以月均温高于 −5℃、月降水低于 200 毫米为游戏筛选。技术和设施可以改变实际施工条件，不把其他月份绝对禁建。
- 洪涝暴露由与河湖的接近程度、相对高程和低地平坦性估计，不是概率、重现期或实际洪水淹没线。
- 农业、水源的淡水季节可靠性及地形形成自然承载基础指数。它不直接换成人口上限，实际人口还受粮食调入、住房、服务、能源和制度影响。

高而平的高原不会仅因为海拔高就失去适建候选资格。干旱地可以通过供水工程开发；候选面积仍可能与耕地、森林重叠，实际项目必须进行用地占用与权利检查。当前没有虚构规划审批、实际建筑、生态保护区或人口。

相邻地块另有 `edge.passage`：在各自真实陆域锚点间采样直线廊道，粗查海洋、湖泊、河网与山地。区分一般陆域、涉河、山地、跨湖、跨海及没有陆域锚点的情况；跨水域不赋予一个假的现成陆路成本。河、湖、海的相交标记分别保留，避免多重约束被单个类别吞掉。

这是候选廊道评估，不是最优寻路、精确桥跨、道路、运力或通行权。路线绕行、行政边界、水权、港口与桥隧工程应随交通项目和国家规则接入。当前采样较粗，不能将其作为局地工程设计。

## 5. 页面、版本与验收

- 新增“地质背景”和“建设条件”，仍一块一色。地质颜色表示区内主导背景，矿床跨多个背景的组成见档案，不用主色抹掉内部差异。
- 图层快捷键为 1—9、0；9 为地质，0 为建设，Home 适应画布（界面 0.6.1 修复，生成器仍为 0.6.0）。
- 档案新增地质与矿藏、土层与侵蚀沉积、自然建设条件以及邻区廊道。矿床中可直接打开对应资源分布。
- 中文语言包承载新标签和说明，没有新增英文语言包。
- 控制测试覆盖赋存背景、有限储量及地块份额总和、海域不分配陆域矿床、泥沙守恒、坡地土层损失、土层容量边界、高原与山地差异、跨水域不能自动当作开放道路、自然环境与分区密度独立，以及原有水与盐账本。

生成器为 0.6.0。地形坐标契约保留，新土层可能改变季节产流、湖泊、农业与淡水潜力，矿产结果也已更换，因此不承诺与 0.5.0 跨版本重现。

## 6. 当前是否可以收尾

**作为国家治理游戏的自然环境底层，可以先冻结这一阶段的功能范围。** 当前已经能回答：土地为何干湿不同、河水来自哪里、季节何时缺水、土壤为何好坏、矿产在哪里，以及哪些地方容易建设、需要什么工程。

剩余应优先随玩法接入：项目实际占地和施工、采矿消耗库存、供水与灌溉实际扣水、人口与产业需求、土地竞争、污染和治理、事件与跨年状态。这些是把环境用于游戏的必要工作；静态调查数据不能冒充已经完成这些玩法。

不必在进入国家玩法前补齐完整板块构造、洋流、气象流体、地下水水头方程或三维矿体。下一阶段更值得验证“国家／人口初始化 → 选择项目 → 月度结算 → 经济民生反馈”的最小治理循环，并据此调整尺度、参数和出生地条件。多种国家开局的资源公平性、60 回合稳定性和项目预算平衡仍属于后续可玩版验收，当前不宣称已经通过。
