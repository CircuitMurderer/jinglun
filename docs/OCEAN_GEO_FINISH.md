# 简化海温、洋流与地理数据收尾（0.9.0）

自然地理阶段在本轮收尾。温度／山系地质关联为 0.8.0，本轮增加静态海洋环流、逐月海表温度及沿海反馈，并统一地理数据口径。计算全部在 Rust，TS 只展示结果。版本变化会改变旧种子的气候、水文和农业；大陆轮廓与构造地形的生成规则保持 0.8.0。

## 1. 模型目的与边界

地球的表层洋流会输送热量，海温也影响向大气提供水汽的条件。本实现只使用这些因果方向，为架空地图提供寒暖海岸差异。[NOAA：海洋环流](https://www.noaa.gov/jetstream/ocean/circulations)、[NOAA：海洋对陆地气候的影响](https://prod-01-alb-www-oe.woc.noaa.gov/ocean-fact/climate/)。

本轮是固定气候常态下的合成表层环流。没有深层温盐环流、真实流速、潮汐、海冰面积演化、厄尔尼诺、西岸强化或逐月变化的洋流速度；不计算船只航速、港口吞吐和运输能力。洋流温度偏差用于气候生成，不能解释为灾害年份的异常。

## 2. 海盆与环流

`crates/world/src/ocean.rs` 使用现有 256×160 自然网格。海洋指原始高程不高于零的采样；内陆湖泊继续由湖盆模型处理，不变成海洋水汽源。

在网格顶点生成流函数：

```text
ψ = sin(π × 纬度 / 50) × d / (1 + d / 12)
```

`d` 为顶点距陆地／边界的采样跳数。所有接触陆地的顶点，以及矩形外边界，严格设为零。相邻顶点的流函数差构成海水穿过网格面的通量；离散旋度使每个海洋采样的流入等于流出，海岸面与地图边界通量为零。

纬度函数形成南北反向的副热带环流和高纬反向环流，海盆形状组织局地绕行。孤立海盆分别闭合，一格宽的海峡可能没有可表达的环流，这是固定分辨率的限制。洋流不左右环绕，也不借道跨过陆地。该环流是风带倾向的参数化，不求解风应力或科氏力方程；不将任意矩形海盆都标为地球上的某条真实洋流。

海水通量全局归一，使最大单采样出流为 0.4 个求解尺度单位。返回向东／向北矢量和 0—1 相对流强；页面显示为 0—100。矢量取面积平均，流强取局部模长的平均，两者不能混用：一个地块内相反流向可能抵消。

## 3. 逐月海温与热量搬运

无环流时的海表温度基准：

```text
年背景 = 28 − 35 × (|纬度| / 75)^1.7
月基准 = clamp(年背景 + 5 × sin(纬度) × cos(2π × (月索引 − 7) / 12), −1.8, 32)
```

月索引从零开始，北半球峰值在八月，南半球在二月；小振幅及相位滞后是海水热惯性的简化。冻结点下限不代表已经模拟海冰。

各月份分别使用正权重迎风格式求平衡海温：

```text
T新 = (0.025 × 当地月基准 + Σ 上游温度 × 流入通量) / (0.025 + 流出通量)
```

迭代至最大月温变化低于 0.00001℃ 或最多 256 次。因流入与流出相等，新值是非负权重的平均，不会产生超出基准范围的极端温度。海洋内部的搬运通量在相邻采样间抵消；恢复项代表与给定辐射背景交换热量，不是完整行星能量预算。

`temperature_anomaly_c` 是搬运后的海温减去同处、同月的无环流基准。向高纬输送暖水和向低纬输送冷水会自然得到不同符号；没有直接给“东海岸”或“西海岸”加固定温度。

## 4. 接入大气、陆地与水文

- 海洋向大气的水汽补充容量乘以 `clamp(exp(0.035 × (SST − 20)), 0.45, 1.55)`。这是有界的相对蒸发／饱和代理，实际补充量继续进入既有逐月水汽账本；不会在内陆额外凭空加雨。
- 海温偏差在海上固定，向陆地进行 40 次有衰减的邻域扩散；陆地每步乘 0.94，最终乘 0.65。它使沿海气温受到影响，内陆影响迅速减弱。扩散跨的是热量影响，不是海水流动。
- 陆地以 0.8.0 的纬度、海拔、海陆性月温为基准，再叠加沿海偏差。十二个月重新平均后得到年均温，再计算潜在蒸散；积雪、土壤、湖泊、地下水、农业与施工窗口使用这一组最终气候。
- 海洋采样以海温作为近海温度代理，继续不生成陆地土壤、作物、本地产流或额外淡水。
- 单向生成顺序为地形 → 海温／环流 → 大气降水 → 陆地气候／蒸散 → 水土与地块汇总。大气不会反过来重新驱动洋流，月间也没有动态海洋储热状态。

## 5. 地理数据契约

每个地块增加 `geography`：

| 字段 | 口径 |
| --- | --- |
| `latitude_deg` | 多边形质心在模型纬度中的位置，北正南负 |
| `area_km2` | 几何面积按既有每地图单位 10 公里换算 |
| `dry_land_area_km2` | 非湖泊陆地面积 |
| `lake_area_km2` | 参考湖面面积 |
| `ocean_area_km2` | 海洋面积；与前两项之和等于地区总面积 |
| `land_elevation_m` | 陆域采样的 mean／min／max，高程含湖床，不含海底；纯海域为 null |

面积组成是有限分辨率估计，再乘精确多边形面积；地块面积之和与模型矩形面积一致，组成比例不是现实 GIS 测量。模型采用等面积游戏网格和线性纬度标签，不是球面投影，也不提供现实经度。

既有 `elevation_m` 仍是含海底的全区均值。海拔图层对陆地为主的地块改用陆域均值，海域为主仍使用全区高程；详情同时说明两种口径，避免混合区的海底拉低陆域高度。

有海洋采样的地块增加 `ocean`；纯陆地为 null。其十二个月海温、偏差与洋流矢量只按海洋采样汇总。陆地气候仍按陆域采样汇总，两组数据独立保存；纯海域的气候也改为全区海洋采样平均，移除原来的质心单点代替。极小无采样地块保留有界单点回退，并补齐自然建设条件；回退不复制矿床库存。

温度图层在陆地为主地块展示陆域气温，在海域为主地块展示海表温度。图例、悬停和着色使用相同口径，海陆混合地块可在档案分别查看两组值；一块一色不变。地块档案显示流向、流强及逐月海温，月份按钮同步现有温度界面。当前没有地图洋流箭头或飞线动画。

`environment.ocean` 返回模型标识 `static_surface_gyres_v1`、等面积海洋采样平均海温、平均绝对偏差及最大绝对偏差。前端校验十二个月、有限数值、面积闭合、海陆字段适用性和矢量范围。中文语言包增加展示键，继续没有英文语言包。

## 6. 指纹与版本

`environment.fingerprint` 仍是辅助重放识别用的 FNV-1a 摘要。0.9.0 纳入生成器版本、网格与尺度、逐月气候／水分、海温／洋流、地下储水／天然矿化度、地质与矿床量等自然数据；浮点按百万分之一单位量化。它能识别年均值相同但月份不同的自然底图，不是安全哈希或存档完整性签名。

同版本同种子确定性、不同 Voronoi 密度下整个 `environment` 一致的测试继续保留。版本是数据契约的一部分；当前前端只接收 0.9.0，没有旧版存档导入与迁移功能。

## 7. 验证与阶段结论

54 项自动测试通过：19 项前端、1 项 HTTP、34 项内核；另显式运行默认忽略的五种子人工审计。新增控制案例覆盖海岸零通量、无散度、陆地屏障隔离、寒暖水输送、南北季节反相、沿海影响衰减、海温影响水汽且保持逐月账本、月份变化可改变指纹，以及混合地块海温与陆域气温分别展示。既有水盐、泥沙、矿床总量和几何测试继续通过。生产构建通过。

本机调试构建中，自然场生成约 3.9—5.1 秒（此前 0.8.0 约 1.4—1.6 秒）；完整接口还包含治理分区和序列化开销。这些是单次开发采样，不是性能保证。月份切换、图层切换不重新求解海洋。

自然地理主干到此冻结：后续优先接入建设、农业、人口、迁徙和月度结算。自然承载／通行／水资源仍是约束与潜力，实际占地、产出、取水和库存消耗需要玩法规则负责。完整动态板块、侵蚀改写地形、冰川、三维海洋与水动力不作为开始治理玩法的前置条件。
