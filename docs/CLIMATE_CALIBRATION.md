# 气候生成质量校准（0.7.0）

本轮针对“地图中部大片干旱、同纬度难以出现湿润沿海地区”的问题。所有计算仍在 Rust 的固定 256 × 160 自然采样上进行；TS 继续显示地块汇总值，一块一色。没有新增前端气候运算、图层或细碎栅格贴图。

## 旧模型的问题

0.6.0 的大气输送在每个纬度行内独立进行，只混合东西两个方向。南北方向的海洋不能向相邻行供应水汽。全年降水先确定，月份仅按权重分配全年雨量，所以夏季不能通过海陆风场变化获得更多全年降水。副热带干燥背景与沿途山地耗水叠加后，容易产生过于连续的干旱区域。

纬度只提供气候背景。海陆布局、季节风向与山地会改变水汽供应；东亚夏季风与梅雨是同纬度湿润环境的现实例子。这里借用这些机制构建游戏代理，不按经纬度复刻中国或其他现实地区。[NOAA：全球环流](https://www.noaa.gov/jetstream/global/global-atmospheric-circulations)、[NOAA：季风的海陆温差与风向变化](https://www.nesdis.noaa.gov/about/k-12-education/severe-weather/what-monsoon)、[中国气象局：东亚夏季风与梅雨](https://www.cma.gov.cn/kppd/kppdqxsj/kppdtqqh/202111/t20211103_4159417.html)

## 每个月的计算

1. 对海陆掩码做宽尺度、横纵分离的滑动平均，形成大陆热力背景。它只依赖自然海岸，不依赖 Voronoi 边界。
2. 按纬度提供信风、西风与极地风的背景趋势。类地季节相位在南北半球反向，热带辐合雨带随月份在南北纬 10° 之间移动。
3. 大陆相对海洋的暖季增热、冷季冷却形成热力梯度代理，叠加到背景风上。海岸附近可以发生季节性风向偏转或反转；不是每条海岸都会成为强季风区。
4. 用四组有向输送近似二维水汽传播：每组沿指定的横向、纵向两条边分流。海面补水的四方向权重受月度风场控制，横纵分流受风的分量控制。水汽可以从北、南、东、西方向进入陆地，不再按行隔离。
5. 海面补充不足的输送水汽；纬度、移动雨带和暖季大陆对流决定基础凝结比例，上坡再产生额外凝结。大陆对流只促使已有水汽降水，不能给无水源的内陆加水。经历山地凝结的气流保留衰减的亏缺标记，用于解释雨影，不凭标记再减少一次水量。
6. 每组流按拓扑顺序遍历，每个采样的水要么降水、要么继续输送并最终离开地图。没有有限迭代截断、补雨或未报告的水汽残量。
7. 十二个月计算完后求和得到年降水。雪、土壤、河网、地下水、湖泊、农业、可用水与建设条件均使用新的月度降水重新计算，不把全年雨量再分配一遍。

四方向流是性能可控的气候近似：每组内部保持方向，不追踪任意转弯或回旋的真实风轨迹，也不解气压、能量和动量方程。其目的在于表现水汽来源、季节偏向、沿途失水及地形差异，不是实际天气预报。

## 标定与保持不变的规则

- 海洋输送能力的低纬基准为 3,600 毫米等效月通量，随纬度和季节调节；它表示气流在一个模型月内的累计水量吞吐，不是瞬时大气柱含水量，也不是海面实际蒸发观测值。参数用低地海岸、内陆与山地控制案例共同检查。
- 雨带、对流、地形抬升分别影响凝结，海陆和山脉决定当地是否实际得到水汽。没有预设某个纬度必为沙漠，也没有指定全球沙漠面积指标。
- 年均温、季节温差及潜在蒸散经验式保持不变。干旱指数仍为年降水／全年潜在蒸散（P/PET），分区阈值仍为 0.2、0.5、1.0；没有通过调低干旱门槛改变地图颜色。潜在蒸散是需求，实际蒸散受水量限制。
- 地形、海岸、地质区和矿床的原始生成方式不变。气候改变后，土层、河湖、水源、农业和自然建设条件可能改变；同一种子不承诺与 0.6.x 重现相同环境。

## 水汽账本

`environment.atmosphere_budget` 保留全年 `evaporation_input`、`precipitation`、`boundary_export`，并增加一月至十二月的 `months` 数组，各项仍是等面积自然采样上的毫米等效通量之和。

```text
每月海洋水汽补充 = 每月降水（含海洋）+ 每月边界水汽输出
全年各项 = 十二个月对应项之和
```

只有陆地降水进入陆地水量桶。陆地实际蒸散目前不再回注大气，所以这是单向耦合的参考气候，不是完整闭合的全球水循环或陆面反馈。地表、地下水、湖泊的储量与盐分仍由原有账本单独核对。

## 控制案例与自动验证

- **跨纬度供水：** 同一行没有海洋，但南侧有海洋，北侧陆地仍能获得降水。
- **同纬度不同地理：** 约北纬 28.75° 的低地海岸年降水约 1,126 毫米，内陆约 219 毫米；沿海 P/PET 超过 1，具备湿润气候条件。
- **季节变化：** 上述海岸六月至八月约 837 毫米，十二月至二月约 60 毫米。这是该控制地形的结果，不是所有地区固定的季节比例。
- **山地阻挡：** 中纬度山地案例迎风侧约 3,765 毫米、背风侧约 315 毫米；移除山脉后同一背风位置约 404 毫米，避免只比较不同地点就声称存在雨影。
- **季节与守恒：** 对称地形南北半球相差六个月；海洋背景雨带随季节移动；逐月水汽守恒；全陆无水源时不凭空降雨；月度输送雨量原样进入陆地水分桶。
- 既有测试继续覆盖确定性、自然环境独立于地块密度、积雪与土壤储量、湖泊地下水与盐分收支、有限矿藏和泥沙收支。

同种子对照采用 `4248287756`、1,000 地块、两次松弛、40% 陆域。相较 0.6.0，Voronoi 多边形与原始海陆地形不变；南北纬 15° 内、陆域占比超过一半的 51 个地块中，主导地形为干旱地的数量从 30 降至 17。这里是显示地块的数量对照，不是面积比例。地块 946（内部编号 945，约北纬 22.7°）年降水从 259 增至 1,221 毫米，体现海洋输送与暖季降水的变化。

## 本轮边界

尚无真实暖流／寒流、逐日天气、台风、厄尔尼诺、真实梅雨锋面、植被蒸散再循环、土地利用反馈或真实球面大气动力学。纬度与距离仍是游戏世界约定。干旱与湿润区应由地理关系自然形成，无法保证任意种子都拥有所有现实气候类型。当前模型适合作为农业、水利与建设玩法的自然底层，后续可随玩法需要继续校准。
